MSIP Label Scanner

Local file scanner - No external connections

Drag and drop files here or click to select

Supports individual files and .ZIP archives (recursively scanned)

About

  • Runs locally via python app.py - accessible at http://127.0.0.1:5000
  • Scans embedded sensitivity/MSIP label metadata only
  • Shows Label ID, where it came from, description, parent labels, label name
  • Flags multiple labels and potential label changes
  • Marks files with no label as "no label detected"
